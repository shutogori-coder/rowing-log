# 文章自然化ツール（AI文章自然化・表現置換ツール）

AIが書いた文章や硬すぎる文章を、自分で登録した置換ルールと文体設定にもとづいて、自然で読みやすい文章に整えるWebアプリです。

- **完全無料**：API・サーバー・データベースは使いません。
- **インストール不要**：`index.html` をダブルクリックするだけで動きます。
- **データは外に出ません**：文章もルールも、あなたのブラウザの中だけで処理・保存されます。

> ※文章の読みやすさや自分らしい表現への改善が目的です。AI判定ツールの回避を保証するものではありません。

---

## 1. 起動方法

1. このリポジトリをダウンロードします（GitHub の「Code → Download ZIP」で取得して展開）。
2. フォルダの中の **`index.html` をダブルクリック**します。ブラウザで開けば使えます。

※ Chrome / Edge / Safari / Firefox の最近のバージョンで動作します。

## 2. 使い方

1. **① 変換したい文章** に文章を貼り付けます。
2. **② 置換ルール** に、自分がよく使う言い換えを登録します（例：さまざまな→いろいろな）。
3. **③ 文体** を選びます。
4. **④ 変換する** で、次のどちらかの方法を選びます。

| 方法 | 内容 | 費用 |
|---|---|---|
| **A. 置換ルールだけ適用** | 登録したルールをそのまま置換します。一瞬で終わりますが、文脈は考えません（「全て→全」だと「全ての」が「全の」になる）。 | 無料 |
| **B. Claude.aiで自然化** | ①「依頼文をコピー」を押す → ② Claude.ai のチャット欄に貼り付けて送信 → ③ 返ってきた文章をツールに貼り付けて「比較する」。文脈を考えて自然に直してくれます。 | 無料（Claude.ai の無料プランや加入中のプランの範囲内） |

5. **⑤ 変換結果** で、変換前後の色分け（赤＝変更前、緑＝変更後）と変更一覧を確認できます。「コピー」「入力欄に反映」「元の文章に戻す」も使えます。

ルールと文体の設定はブラウザに自動保存されます。別のPCやブラウザへは「ルールを書き出し」「ルールを読み込み」で移せます。

## 3. 設計

```
index.html（画面）
  └ ブラウザの中だけで完結
     ・置換ルールの適用、差分の色分け
     ・Claude.ai 用の依頼文を作成（AI へは自分で貼り付ける）
     ・ルールと設定は localStorage に保存
```

### ファイル構成

```
index.html          画面
css/style.css       見た目（色は先頭の変数でまとめて変更可、ダークモード・スマホ対応）
js/rules-core.js    置換ルールの計算（一括登録の解析、機械的な置換）
js/prompt.js        Claude.ai 用の依頼文づくり・文体の説明  ← AIへの指示を調整したいときはここ
js/storage.js       保存・書き出し・読み込み
js/diff-view.js     差分の色分け表示、変更一覧の作成
js/rules-ui.js      置換ルールの画面操作
js/app.js           画面全体のまとめ役（変換、結果表示、コピー、元に戻す）
vendor/diff.min.js  差分計算ライブラリ jsdiff（BSDライセンス、vendor/diff.LICENSE.txt）
test/               自動テスト（Node.js がある場合 `npm test` で実行）
```

`index.html` の最後で、上から順にスクリプトを読み込んでいます。後のファイルは前のファイルの機能を使うため、この順番は変えないでください。

### よくある修正

- **文体を追加したい** → `js/prompt.js` の `STYLES` に追加し、`index.html` の `<select id="styleSelect">` に同じキーの `<option>` を追加。
- **AIへの指示を調整したい** → `js/prompt.js` の `INSTRUCTIONS`。
- **初期ルールを変えたい** → `js/rules-core.js` の `DEFAULT_RULES`。
