# 文章自然化ツール（AI文章自然化・表現置換ツール）

AIが書いた文章や硬すぎる文章を、自分で登録した置換ルールと文体設定にもとづいて、自然で読みやすい文章に整えるWebアプリです。

> ※文章の読みやすさや自分らしい表現への改善が目的です。AI判定ツールの回避を保証するものではありません。

---

## 1. 使い方（起動手順）

必要なもの: [Node.js](https://nodejs.org/) 20 以上

```bash
npm install              # 初回のみ
cp .env.example .env     # 初回のみ。.env に ANTHROPIC_API_KEY を書く
npm start                # → http://localhost:3000 を開く
```

- **APIキーがなくても動きます。** その場合は「置換ルールの機械的な適用」だけが使え、AI自然化のチェックボックスはOFFのままになります。
- APIキーは [Anthropic Console](https://console.anthropic.com/) で発行し、`.env` の `ANTHROPIC_API_KEY=` の後ろに貼り付けて、サーバーを再起動してください。
- テスト: `npm test`

## 2. 機能

| 機能 | 内容 |
|---|---|
| 文章入力 | 長文・貼り付け対応、文字数表示（AI使用時は上限超過を赤表示） |
| 置換ルール | 追加・その場で編集・削除・有効/無効の切り替え、まとめて登録（`前→後` / `前,後` を1行1件）、JSON書き出し・読み込み、初期ルールに戻す。ブラウザに自動保存 |
| AI自然化 | ルールを「文脈に合う箇所だけ」適用し、意味・事実・数値を変えずに文体を整える |
| 機械的置換 | AIを使わず、ルールを長い語句優先でそのまま置換（AI OFF時） |
| 文体設定 | 大学生のレポート風 / 卒業論文風 / ビジネス文章風 / 一般的で読みやすい文章、である調 / です・ます調 |
| 結果表示 | 変換前後を並べて表示し、変更箇所を色分け（赤=削除・変更前、緑=追加・変更後）。変更一覧に「ルール」「AI」の区別と理由を表示 |
| 操作 | ワンクリックでコピー、変換後を入力欄に反映、元の文章に戻す |
| スマホ対応 | 幅700px以下で1列レイアウト |

### 機械的置換とAI自然化の違い
機械的置換では「全て→全」のルールで「全ての学生」が「全の学生」になってしまいます。
AI自然化では、こうした不自然な置換はせず「全学生」のように文脈に合う形でだけ適用します。

## 3. 設計

### 構成図

```
ブラウザ（public/）                         サーバー（server/）                 Claude API
┌──────────────────────────┐   POST /api/naturalize   ┌──────────────────────┐        ┌──────────┐
│ 入力・ルール・文体・結果表示 │ ───────────────────────▶ │ 入力チェック            │ ─────▶ │ 文章自然化 │
│ ルール/設定は localStorage  │ ◀─────────────────────── │ プロンプト組み立て       │ ◀───── │ (JSONで返す)│
│ 機械的置換・差分表示もここ   │   {text, changes}        │ APIキーはここだけ(.env) │        └──────────┘
└──────────────────────────┘                          └──────────────────────┘
```

- **APIキーはサーバーの `.env` にだけ置き**、ブラウザには一切送りません。
- 置換ルールと設定はブラウザの localStorage に保存します（データベース不要）。別の端末へは「書き出し」「読み込み」で移せます。
- 差分表示は、日本語を単語単位に分割（`Intl.Segmenter`）してから [jsdiff](https://github.com/kpdecker/jsdiff) で比較しています。
- AIには「修正後の文章」と「変更一覧（変更前・変更後・ルール/AI・理由）」をJSON形式（構造化出力）で返させています。

### ファイル構成

```
server/
  index.js        Webサーバー本体（画面の配信、/api/health、/api/naturalize、エラー処理）
  naturalize.js   Claude API の呼び出し、応答の解析、エラーを日本語メッセージに変換
  prompt.js       AIへの指示文・文体の説明・出力形式  ← 言い回しを調整したいときはここ
public/
  index.html      画面
  css/style.css   見た目（色は先頭の変数でまとめて変更可、ダークモード対応）
  js/app.js       画面全体のまとめ役（変換、結果表示、コピー、元に戻す）
  js/rules-core.js 置換ルールの計算（一括登録の解析、機械的置換）
  js/rules-ui.js  置換ルールの画面操作
  js/storage.js   保存・書き出し・読み込み
  js/diff-view.js 差分の色分け表示
  js/api.js       サーバーAPIの呼び出し
test/             自動テスト（ルール処理、サーバー処理を偽のAPIで確認）
```

### よくある修正

- **文体の説明を変えたい / 文体を追加したい** → `server/prompt.js` の `STYLES` を編集し、`public/index.html` の `<select id="styleSelect">` に同じキーの `<option>` を追加。
- **AIへの指示を調整したい** → `server/prompt.js` の `SYSTEM_PROMPT`。
- **初期ルールを変えたい** → `public/js/rules-core.js` の `DEFAULT_RULES`。

## 4. 費用と設定（.env）

| 変数 | 既定値 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | なし | 未設定ならAI機能は無効 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 品質重視の既定値。費用を抑えるなら `claude-sonnet-5-5`（約半額）や `claude-haiku-5-5`（大幅に安い） |
| `CLAUDE_EFFORT` | `medium` | `low` にすると速く安くなる |
| `MAX_INPUT_CHARS` | `20000` | 1回で変換できる最大文字数 |
| `PORT` | `3000` | |

- 料金は使った分だけです（Claude API の従量課金）。ルールの機械的置換だけなら費用はかかりません。
- サーバーはデータベース不要の小さな Node.js アプリなので、Render・Railway・Fly.io などの無料〜低価格枠や自分のPCで動かせます。デプロイ先では `.env` の代わりに各サービスの「環境変数」設定画面に `ANTHROPIC_API_KEY` を登録してください。
- AIが文章の処理を断った場合は、対応モデルでは自動で別モデルに切り替えて再実行します（サーバー側フォールバック）。

## 5. エラー表示

エラーは画面の変換ボタンの下に、原因と対処が分かる日本語で表示されます（例: 「APIキーが正しくありません。サーバーの .env の ANTHROPIC_API_KEY を確認してください。」）。サーバーのターミナルにも同じ内容と詳細が出力されます。
